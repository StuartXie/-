# 综合测评智育学分成绩计算器

## 下载

直接下载 **学分成绩计算器.html** 即可。

## 使用方法

1. 进入学工系统的学生成绩页面。

   ![学工系统](image/001.png)

2. 右键保存（另存为），下载得到网页“学生成绩单.html”。

   <p align="center">
     <img src="image/002.png" width="45%">
     <img src="image/003.png" width="45%">
   </p>

3. 打开学分成绩计算器，直接将“学生成绩单.html”拖入网页。

   ![导入成绩](image/004.png)

4. 选择学期，如 2025-2026-2、2025-2026-1，即可得到 2025-2026 学年的平均学分成绩。

   ![计算结果](image/005.png)

5. 可根据需要，选择包含在计算中的课程。

> 在遵守 MIT 许可证的前提下，可根据自身需要修改代码。
